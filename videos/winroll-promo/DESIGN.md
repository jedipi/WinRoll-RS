# WinRoll RS promo identity

## Overview
WinRoll RS uses a light desktop-utility identity, with large sans-serif headings and a single rust accent.
The actual Windows screenshots do the product explanation.
Layouts are asymmetric, roomy and anchored to edges.
The promo should feel responsive and practical, never like a gaming or futuristic product.

## Colors
- Primary surface: #FDFDFC.
- Primary text: #242622.
- Accent: #AD4227.
- Secondary surface: #FBF3EE.
- Dividers: #DDD9D5.
- Secondary text: #60616B.
These are the exact values from capture/extracted/tokens.json.

## Typography
- Segoe UI Variable / Segoe UI, with Arial fallback.
- Display weight 700; body weight 400; logo weight 650.
- Video display size 110-144px; body 36-44px; labels 24-30px.
- Tight display tracking, natural wrapping and clear reading time.

## Elevation
Product screenshots keep their real window shadows. Avoid adding heavy shadows or glass.
Use the tinted surface only for a supporting panel. One consistent 12px corner radius.

## Components
- Outlined-window WinRoll RS wordmark, with RS in rust.
- Actual desktop screenshot, uncropped at its intrinsic aspect ratio.
- Empty-caption right-click gesture illustration.
- Rolled-window movement illustration, with four-way cross.
- Actual Windows tray menu, preserved and readable.
- Charcoal release call to action and GitHub repository address.

## Do's and Don'ts
### Do
- Keep each scene's main message short and readable at a glance.
- Use the real screenshots and the user's revised gesture illustrations.
- Keep the source image aspect ratios intact.
- Make motion emphasize the gesture or the next useful action.
### Don't
- Invent download availability, compatibility guarantees, prices or metrics.
- Reintroduce the removed compatibility/recovery blocks.
- Use purple glows, device mockups or fake product interfaces.
- Put the click cursor over title-bar control buttons.
