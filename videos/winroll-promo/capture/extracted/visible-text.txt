[a] How it works
[a] Get started
[h1] Keep it open.
[span] Make room.
[p] Roll eligible windows up to their title bars with a right-click. Unroll them when you need them. Keep your workspace open and clear.
[a] View releases
[a] See how it works
[h2] Right-click.
[span] Roll up.
[p] Keep the windows you're not using open and within reach. Unroll them when you're ready.
[h3] Right-click an empty caption
[p] Right-click an empty caption area of an eligible window to roll it up. Right-click again to unroll.
[h3] Drag to move
[p] Left-drag a rolled title bar to move the window. Its contents stay collapsed. A plain left click focuses it.
[h2] Control from the tray
[p] Keep windows rolled, unroll when needed, and exit safely.
[dt] Pause / Enable
[dd] Pause gestures and keep windows rolled. Enable resumes gestures.
[dt] Unroll all
[dd] Expand managed windows. Keep the current pause mode.
[dt] Exit
[dd] Unroll before quitting. Retry from the tray if expansion fails.
[h2] Get started
[p] One portable x64 executable, written in Rust. No injected DLL. Run normally, without administrator privileges.
[a] Read the usage guide
[h3] Build from source
[p] Requires Rust's Windows MSVC toolchain, Visual Studio C++ build tools and Windows SDK.
[code] git clone https://github.com/jedipi/WinRoll-RS.git
cd WinRoll-RS
cargo build --release --locked
.\target\release\winroll.exe
